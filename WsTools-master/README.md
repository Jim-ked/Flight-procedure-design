# 飞行程序设计基础工具包

#### 介绍
飞行程序设计CAD插件及其它辅助工具。软件不定期进行更新，如果您使用的版本过期，请重新从网站下载或联系作者获取最新版本。

#### 软件架构
软件包分为四个部分   
1、Annex14(附件14面评估工具)。   
该工具主要用于机场净空评估功能进行测试使用，坐标换算按照标准椭球体坐标进行。

2、PANS-OPS-OAS（ICAO OAS参数生成软件）。   
ICAO网站提供的OAS参数生成软件，很多朋友反馈ICAO网站上已经找不到了，所以在这里提供一下。目录中包含的WsOasPara.exe文件是参照ICAO软件设计开发的中文版参数生成软件，仅供参考。

3、WindSpiral2026 CAD插件。   
该部分主要为飞行程序设计而制作的CAD插件。

该插件分别对应AutoCAD、中望CAD、浩辰CAD。请根据CAD软件类型，使用各自的CAD插件。

插件使用方法为：在CAD中通过netload 命令加载对应插件，通过wstools命令显示出插件的功能窗口，按照相关提示进行操作。

相关插件的使用样例，详见微信公众号：风螺旋线、知乎专栏：等距螺旋的算法之路。

4、WsGis（坐标换算工具）。  
该工具提供了54坐标系、2000坐标系经纬度换算为XY坐标的功能，可用于基础数据的转换。

5、其它内容。  
根据大家的需求，不定期更新飞行程序相关的课件和资料。
#### 安装教程

软件包中的所有工具均为绿色免安装程序。
CAD插件通过CAD内部的netload命令进行加载。
