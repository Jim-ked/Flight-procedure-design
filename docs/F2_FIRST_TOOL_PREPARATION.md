# F2 首个 WindSpiral 工具接入准备

2026-11-07，离线准备。F0.1/F1 实际交付状态以各自验收报告为准，本文不表示已接入专业计算。

优先选择 **A2 中的离场转弯点距离计算**，不一次迁移整个 A2 或 WindSpiral。依据 `recovered/A2-BasicCalculation/final-static-closure.md`、`overview.md`、`cad-interactions.md`：六类数值计算、事件、参数单位、绘图和序列化链已静态闭合，数值切片已有测试，API25.1兼容编译已有记录；离场 TP 输入可以直接消费 F1 的独立 DER 数据，形成较小的真实使用闭环。

A3 同样 COMPLETE_STATIC，但涉及设施精度角、DME三弧、盲区及多类几何，且规范来源存在未决项。其恢复文件明确没有双台交叉定位实现，不宜把帮助文案当作可用功能。A3 作为后续候选保留。两者都没有当前插件中的真实宿主运行证明，旧 net48 DLL 不能直接作为 net8 组件加载。

## F2 具体范围

- 独立紧凑参数窗，可直接调用，不要求先建 Procedure。
- 起点从项目跑道 DER 选择或 CAD 拾取；方向可用跑道外延或再拾方向点，不能把磁航向当格网方向直接绘制。
- 输入 DER 标高、目标转弯标高、爬升梯度 %；明确高程基准和单位。恢复公式 `d = 100 × (TurnAlt − DER elevation − 5) / PDGPercent` 中的 5 m 是现存代码常量，其适用规范必须取得确切条款证据后确定产品默认与限制，不能仅凭历史代码宣称合规。
- 复用 `BasicCalculation.Recovered.cs` 的实际数学切片及测试向量；对零/负梯度、无效高度差和取消输入给出明确行为。若为安全输入校验改变旧行为，在适配测试中单列差异。
- 按恢复链绘制距起点 d 的施工位置、垂直方向的 20,000 m 原生横线及 TP/距离文字；采用统一专业图层，一次命令和事务，支持原生编辑与撤销。
- 后续确需读取施工参数时，再决定是否适配 WsCalcuLine；不为本工具强建通用实体身份或生命周期。旧 XData 的 Unicode 字段必须按恢复 schema核对，不能改名后宣称兼容。
- Core 对照历史数值与独立计算，CAD 验证两途径输入、取消、坐标/方向/线长/文字、保存重开、U；保留真实图面截图。

不在 F2 首项开发完整离场保护区、障碍物评价、AIP/ARINC输出、全部A2/A3或A1风螺旋。A1公共速度/转弯参数只在确定调用需要时复用，依据 `recovered/A1-WindSpiral/final-input-semantics.csv` 及 final-static-closure，避免无需求搬迁。
