## 发布与既有启用项目的复核

- 当前交付包 artifacts/netload/csv-import-20261109：5个项目、3个程序声明块均可从随附库取得，资源文件与源码一致。
- 旧标准Release目录 src/Fpd.AutoCAD/bin/Release/net8.0-windows：精简库仅4块，缺NVORDM，来源记录缺失；旧包不作为当前发布包。禁止通过改用户项目DWG填补。
- B04/B05：现用VOR/DME附加几何与单台规范图例有差异，统一重审；B05A NDME为替代候选，尚未启用。
- B02/B03：原障碍物底圆为空心，正式图例使用底部实点；标高/高度及灯光属性来源也未完成。
- P01/P02/P03：通过方式与报告要求不能互斥混用；旧SymbolKey迁移不得自动推断缺失的报告要求。
- 图形存在、现有映射启用、规范一致和正式批准是四种不同事实。所有“有条件使用”仍须明确适用限制，本轮批准数0。
