# 独立路径及公共底图迁移说明

旧JSON通过ProjectStore.Open读取时，旧FixIdents主顺序与每个Sections项分别迁移为独立路径，不合并、不去重、不排序。旧主顺序命名为“旧主顺序”，旧段保留名称；名称冲突仅增加后缀。Runway、Missed、旧Stage/Branch说明保留，迁移说明明确旧段未认定为完整运行路线。旧字段保留作为历史资料，不再作为当前程序页的编辑目标。

新建路径必须由设计员命名。ProcedureId、PathId独立于名称；旧文件缺少这些ID时按原项目ID和原次序确定，首次保存后持久化。每次Fix使用保存独立SymbolKey和可选Annotation，同一项目Fix可多次引用。Fix更名/删除同步所有新路径及旧引用。跑道六位置、标高和导航设施类型/单位/独立LOC与GP字段保持原模型。

第一次覆盖旧项目JSON前，ProjectStore.Save将原文件原样保存为同目录`.pre-paths.bak`；已存在的备份不覆盖。新格式仍保留旧字段，但旧版软件无法编辑新Paths，因此不要用旧版覆盖新文件。项目JSON与DWG须分别保存，不构成跨文件原子事务。

四类基础资料新增DataId，旧数据默认值按项目ID/类别/标识确定，改名保持该ID。公共图形以实体扩展字典FPD_BASE_V1记录项目、数据ID、成组数量、资料指纹及几何指纹。重开、刷新和程序切换不追加同一底图。数据改动只更新标记完整且几何未被修改的图形；移动、改名、丢失部分实体或重复标记均保留并报告冲突。删除资料默认保留已绘图形。需要时由“更多→保留冲突原图并补建”明确创建新图，旧图不删除。

普通绘图不改变DWG关联。“更多→关联当前DWG”只接受已保存的绝对DWG文件路径。未打开关联图时数据仍可录入/保存，底图不写入其他图；打开关联图后补建。CAD原生撤销仅撤销DWG图形，不倒退JSON数据，用户可按需再次补建。

程序图符按稳定ProcedureId归属`FPD_P_<ID摘要>_SYMBOL`原生图层，不按路径创建图层；同程序各路径相同Fix/图符合并，文字注记独立。程序图符由明确操作生成，不把序列当TF航迹，也不生成保护区。图层显隐、冻结和编辑使用AutoCAD原生工具。
