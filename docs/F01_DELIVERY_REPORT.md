## 实现范围

- 保留 AutoCAD 2026 / .NET 8 / WinForms PaletteSet、四栏导航和工具固定窄侧栏。WorkspacePanel 按四页拆为 partial 文件，没有新增通用框架或专业算法。

- Fix / Obstacle 表支持手工增改删、标识查找、多选、CSV、带标题 TSV 复制/粘贴新增、所选及全部绘图。整批解析成功才写项目，重复标识、缺字段及无效坐标报告行号。
- 障碍物分别保存顶标高、自身高度、地面高程。顶标高必填，绝不以自身高度代替。
- 批量绘图为一次 CAD 命令、一次事务，使用真实 WCS 投影坐标。FPD_FIX 为绿色圆十字符号，FPD_OBSTACLE 为红色三角；原生块属性显示名称和可选顶标高，字高可设置，默认 50 m。用户可原生编辑，不自动覆盖已有图形。
- FPDPOINT 仍生成 DBPoint，新增名称文字；必须明确选中一个 Fix，未选中不会隐式绘制 ARP。
- 程序页选择已有 Fix 追加、删除引用、上移/下移，允许重复，刷新保留当前程序。无需完整专业编码表。
- 工具页明确选择 ARP / 单个或批量 Fix / 障碍物，转换结果在当前工具旁显示。
- 成果页读取当前 DWG 的实际 FPD 图层，提供显示/隐藏、图面定位、Fix/障碍物 CSV 导出和程序顺序 JSON 导出。未开发专业成果不生成模拟数据。
