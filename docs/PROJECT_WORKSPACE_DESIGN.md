# 项目工作区现行设计

本文件是项目模块唯一现行设计，替代 F0/F1 项目管理方案。其他 F0/F1 设计、交付记录及恢复资料仅为历史证据，不指导本模块新开发。程序组织、专业图符、复飞、等待、标称航迹和保护区算法不在本轮范围。

## DWG 生命周期

一张 DWG 对应一个项目。入口为 AutoCAD 原生 NEW/OPEN；项目新建在当前 DWG 中初始化资料，不更换或清空图形。当前 Document/Database 是会话身份，禁止独立选择 JSON、路径匹配和人工关联。每个打开文档有独立状态，关闭释放状态。

辅助文件为 `Path.ChangeExtension(dwg, ".fpd.json")`。业务编辑同时在 DWG 命名对象字典保存 JSON 快照，使原生保存提示、撤销、另存和业务资料一致；不包含生成/还原图形指令。原生保存成功后导出同名辅助 JSON；失败保持明确错误状态，不报告资料已保存。未命名 DWG 的数据仅在当前文档中，须原生保存。

重开优先使用 DWG 快照；旧 DWG 无快照时才读同名辅助 JSON。发现两者不一致时使用该 DWG 内快照并提示。没有辅助 JSON/快照时显示未初始化项目，绝不删除、重绘、还原 CAD 实体。历史 DwgPath 仅作反序列化兼容，运行时由文档维护，不参与关联，不写入新 JSON。

## 四类基础资料

- 定位点：Ident、Latitude、Longitude；DBPoint + 独立名称文字。旧 Elevation 仅兼容原文件，不录入；已知旧CAD Z兼容保留，不用作程序高程。程序类型和程序高程属于未来路径引用接口，本轮不实现。
- 障碍物：Ident、Latitude、Longitude、TopElevation、GroundElevation；自身高度显示为顶标高减地面高程，不重复录入。WindSpiral 原始 Obst 块，Z=顶标高，仅另标编号。
- 导航台：Ident、Kind、绝对 Latitude/Longitude；原始块按审计映射使用，仅标代号。旧频率等资料兼容保存，但不进入新基础录入和 CSV；不增加容差、半宽、扩张角等计算参数。
- 跑道：宽度、两个相反方向编号、两个物理端的经纬度及标高。每方向 THR 默认本物理端、DER 默认对端物理端。内移 THR 和特殊 DER 可独立覆盖；旧六组数据按实际差异保留。轮廓保留两物理端标高，仅标方向编号及必要 THR/DER 位置。

所有基本坐标按 ARP 选定 CGCS2000 三度带中央经线。手输接受十进制度或度分秒；CSV 只接受十进制度。CAD X=东、Y=北，米制；缺失高程仅绘图使用 Z=0，占位不得写回为真实高程。

## 交互与 CSV

顶部仅项目/机场名称、ARP、坐标摘要和项目操作；新建/编辑共用简单窗口。下方为定位点、障碍物、跑道、导航台四标签，搜索、编辑、整类 CSV 导入/导出/模板、绘制所选/全部及列表。不提供单条 CSV 功能。

CSV 定义由 Core 中四个 Csv 类统一提供：模板调用同一个 Export 空集合；导入严格核对字段顺序和列数。跑道 CSV 物理端必填，THR/DER 三字段整组留空表示默认。导航台没有相对输入。所有编辑窗口可手输和 CAD 拾取，取消不改坐标；另提供 POINT 原生点登记并复用该 DBPoint。

项目页提供坐标转换明确入口，复用 Cgcs2000Projection 正反算，显示经纬度和 XYZ、复制、CAD 拾点。WsGis 手册为旧 .NET Framework 4.5/Proj4Net 工具，支持多坐标系及独立跑道/极坐标语义；其样例是经度在前，不能当作本 CSV 模板。核查样例 CM105 的东/北值和现算法；不加载旧 EXE/DLL。

## 图层与实体更新

仅四公共图层 FPD_FIX/FPD_OBSTACLE/FPD_RUNWAY/FPD_NAVAID 随页面显示。项目页显示、程序页关闭；拾取临时显示相关公共参考图层并在 finally 恢复原 off/frozen 状态，其他图层不改。

编辑后更新、绘制所选、绘制全部和 FPDPOINT 使用同一实体身份/指纹同步。无变化不插入；数据改变且图形未变才更新；人工改动、部分删除、重复实体均提示冲突并保留，不自动补回。DWG 保存/打开/切换从不同步图形。数据删除保留既有图形。历史实体没有可靠身份时提示冲突，禁止静默接管或重叠补建。

## 验收与未决项

保留现有构建和 Core 基础检查，主要验收是在 AutoCAD 新 DWG 中创建项目、录入四类资料、CSV 往返、页面图层切换、原生保存重开及人工改图保护。只记录实际完成操作，宿主未执行的步骤不得写为通过。WindSpiral 原始导航台/障碍物映射须基于已有块表审计；ILS 原始台站块尚未确认，保留资料并提示未绘制，不把 NLOC 猜作 ILS，不新增 GP/保护区业务。
