# A10 输入点与人工交互

| 输入 | 事件 | 用户选择 | 进入计算 |
|---|---|---|---|
| O | P2D8 / 0x379FC | 导航台位置 | `r`、两个方位、扇区中心 |
| IF | P2D9 / 0x37B24 | IF 点方向 | `r` 与 IF bearing |
| IAF | P2DA / 0x37C54 | IAF 点 | 仅 IAF bearing |

软件没有从已有实体或 XData 自动推导这些点；它只取 GetPoint 的 XY。已有程序数据若被外层保存，可以推导候选点，但原窗口没有这种调用证据。输入 TextChanged 只做数值格式校验和颜色提示。
