功能简介

【飞行程序基础计算】是一个综合计算模块，集成了 FAF、SOC、C 容差以及离场 / 复飞转弯点等常用距离计算。每个计算功能都包含参数输入、示意图预览、文字标注选项与 CAD 绘制。

公共元素与通用操作

每个选项卡都包含相同的三类公共控件：

控件说明
示意图区显示当前计算模型的几何示意图，用于绘制前核对。
【文字标注】勾选（默认开）后，绘制时一并标注计算文字。
【CAD】把当前选项卡的计算结果绘制到CAD窗口；绘制时按命令行提示拾取基准点与方向。

通用操作步骤

  • 命令行输入 Y02_基础计算 打开窗口。
  • 切换到需要的选项卡（FAF / 非精密SOC / 精密SOC / 复飞TP / 离场TP / C容差）。
  • 填写该选项卡的参数，结果框与示意图会随参数自动更新。
  • 如需标注文字，保持【文字标注】勾选。
  • 点击【CAD】，按命令行提示拾取基准点与方向，把结果绘制到CAD窗口。
提示：各选项卡相互独立，分别对应不同的计算模型；灰色结果框为自动计算结果，无需手工输入。

选项卡一：FAF计算

界面截图

参数说明（进近程序参数）

控件默认值说明
中间段长度(m)10000IF 至 FAF 的中间进近段长度。
FAF高度(m)900最后进近定位点高度。
入口标高(m)300跑道入口标高。
GP角度(°)3下滑角。
RDH(m)15入口基准高。
FAF-THR(m)11162FAF至入口距离 = (FAF高度 − RDH − 入口标高) ÷ tan(GP角度)，随参数自动重算。

操作步骤

  • 填写中间段长度、FAF 高度、入口标高、GP 角度、RDH。
  • 软件自动计算 FAF 至 THR 距离。
  • 点【CAD】，按提示拾取位置点，指定方向进行绘制。

选项卡二：非精密SOC计算

界面截图

参数说明

控件默认值说明
复飞参数计算IAS380 / 高度900 / 坡度25 / 温度15 / 风速19IAS(km/h)、高度(m)、坡度(°)、温度(℃)、风速(km/h)；IAS 与风速可点击标签更换数据单位（nm）。
计时(sec)18复飞点（MAPt）定位容差最晚点与SOC之间的飞行时长。
距离(m)772结果：计时飞行距离 = (TAS + 风速) × 计时 ÷ 3.6，自动计算。

操作步骤

  • 在“空速计算”面板填写高度、IAS、温度、风速等参数。
  • 核对自动计算的计时与距离。
  • 点【CAD】，依次拾取“复飞定位容差最晚点”与“复飞方向”进行绘制。

选项卡三：精密SOC计算

界面截图

参数说明（精密进近参数）

控件默认值说明
GP(°)3.0下滑角，下拉选择 2.5～3.2（超过 3.2 时 APV 计算方法不同）。
Xz(m)-900THR—SOC 距离的偏移修正量，下拉选择 -900 / -1100 / -1400。
DH(m)60决断高。
标高(m)1800机场标高；高于 900m 时自动对 HL 作标高修正。
机型D航空器分类 H / A / B / C / D，决定 HLm 与 HLr 取值。
HLm(m)49气压高度表高度损失，按机型自动取值，不可手输。
HLr(m)26无线电高度表高度损失，按机型自动取值，不可手输。
HL修正(m)52.12实际采用的 HL：标高 > 900m 时为 HLm + HLr × 0.02 × 标高 ÷ 300，否则等于 HLm；可手改。
SOC高(m)0SOC 高度 = DH − HL修正，自动计算。
THR-SOC(m)0THR至SOC 距离 = (DH − HL修正) ÷ tan(GP) + Xz，自动计算。

操作步骤

  • 选择 GP 角度、Xz、机型，填写 DH 与机场标高。
  • 核对自动计算的 HL修正、SOC高、THR-SOC 与示意图。
  • 点【CAD】，按提示拾取“跑道入口点”与“复飞方向”进行绘制。
