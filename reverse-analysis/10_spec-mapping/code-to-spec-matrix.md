# 规范映射基线

采用项目提供《航空器运行目视和仪表飞行程序设计规范》，AC-97-FS-005，民航规〔2020〕12号，2020-05-19。当前没有用规范补写代码。精确章节必须在业务算法恢复后逐项核实。

| 代码行为 | 代码证据 | 规范条款 | 实现完整度/疑点 |
|---|---|---|---|
| 定高距离=(转弯高度-alt1-5)/(梯度/100) | P0x06000285/286，A | 待确认 | 含5常量及零梯度不更新，不能先声明规范符合 |
| TP后计算高度固定使用0.1，参考高度使用输入梯度 | P0x06000287/289，A | 待确认 | 实现依据待确认，需核对两高度的用途 |
| KK/C拾取到TP为无符号平面距离 | P0x0600028A/28B/28E，A/B | 待确认 | 人工共线/前后意图与下游符号处理尚未闭环 |
| OAS参数查表并解码缩放 | `_0088_0090_0094`，A | 待确认 | 数据版本、参数语义及插值范围待恢复；实现依据待确认 |

目前无充分证据将实现归属于其他版本 ICAO Doc 8168、旧国内规范或作者简化。以上“待确认”不是已发现违反规范，也不是符合性证明。对旧模板/4D OAS资料只先保留年代和来源，不据此指定当前DLL版本依据。
